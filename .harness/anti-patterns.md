# Naver Cafe Auto Manager - Anti-Patterns Guide

본 문서는 개발 및 운영 과정에서 재발 방지를 위해 반드시 회피해야 할 코드 작성 패턴 및 운영 금지 조항(Anti-Patterns)을 정의한 규칙 집합입니다.

---

## 🚫 1. [환경 변수] load_dotenv() 기본 옵션 호출 금지
* **안티패턴**: `load_dotenv()`를 옵션 없이 호출하는 행위.
* **문제점**: 윈도우/리눅스 OS 시스템 환경변수에 레거시/오류 키가 상주할 경우 `.env` 파일에 새로 기입한 올바른 API 키가 덮어써지지 않아 계속 인증 에러(401 Unauthorized)가 발생함.
* **올바른 패턴**: `load_dotenv(override=True)`와 같이 `override=True` 파라미터를 반드시 명시하여 프로젝트 `.env` 키가 항상 최우선으로 시스템에 주입되도록 보장함.

---

## 🚫 2. [비동기 코루틴] 생성자(__init__) 내 asyncio.create_task() 호출 금지
* **안티패턴**: 파이썬 클래스의 동기 생성자 `__init__` 내부에서 `asyncio.create_task()`를 직접 구동하는 행위.
* **문제점**: 모듈 임포트 타임(Import Time)에는 아직 `uvicorn` 또는 `asyncio` 이벤트 루프가 기동되지 않았으므로 `RuntimeError: no running event loop` 서버 크래시를 유발함.
* **올바른 패턴**: `__init__`에서는 변수 및 인스턴스 초기화만 수행하고, 비동기 태스크 생성 로직은 `async def start(self):` 등 이벤트 루프가 확립된 비동기 메서드 내부로 완전 격리함.

---

## 3. [AI 요약 유효성] 과도하게 엄격한 길이 조건(len * 0.5) 강제 지정 금지
* **안티패턴**: AI 요약 응답에 대해 `len(summary_text) < len(text) * 0.5`와 같이 지나치게 짧은 비율 검사만을 강제하는 행위.
* **문제점**: AI가 정성스럽고 풍부한 리포트를 52% 분량으로 리턴하더라도 이 검사식에 걸려 고품질 AI 응답이 버려지고 로컬 무작위 추출 알고리즘으로 하향 우회됨.
* **올바른 패턴**: AI 응답이 유효하고 원문보다 적절히 간결할 경우(`len(summary_text) < len(text)`) AI 결과를 최우선 채택하도록 검증식을 현실화함.

---

## 🚫 4. [Windows Batch] .bat 배치 파일의 UTF-8 저장 금지
* **안티패턴**: 한글 문구가 포함된 윈도우 배치 파일(`clean_archive.bat` 등)을 BOM 없는 UTF-8 인코딩으로 저장하는 행위.
* **문제점**: 윈도우 커맨드 프롬프트(`cmd.exe`)는 배치 파일 파싱 시 ANSI로 해석하려 하므로 `@echo off` 명령어가 `'ho'`로 깨지거나 `if` 조건문 및 한글 문구가 망가져 구문 파싱 에러를 냄.
* **올바른 패턴**: 한글이 포함된 윈도우 배치 파일(`.bat`)은 항상 **ANSI / CP949** 인코딩으로 저장하여 커맨드 프롬프트 호환성을 보장함.

---

## 🚫 5. [네이버 카페 폼] 제목 80자 초과 텍스트 입력 금지
* **안티패턴**: 기사 원문 제목을 정제 없이 그대로 카페 작성 폼에 fill/type 하는 행위.
* **문제점**: 네이버 카페 글쓰기 폼의 최대 제한인 80자를 초과하면 등록 버튼 클릭 시 서버/프론트엔드 유효성 검사에 걸려 등록이 차단되고 `등록 유실 추정` 크래시를 발생시킴.
* **올바른 패턴**: 기사 수집기 및 봇 작성 레이어에서 78자 초과 시 자동 슬라이싱(`[:75] + "..."`)을 거치도록 이중 방어막을 구축함.
