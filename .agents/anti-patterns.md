# 🚫 프로젝트 로컬 안티패턴 (Project Anti-Patterns)

본 파일은 네이버 카페 자동화 프로젝트 개발 중 발생했던 주요 에러 사례 및 부작용 방지 가이드라인을 기록하는 아카이브입니다.

---

## 1. 네이버 카페 모바일 SPA 추측성 검색 URL 사용 및 404 안내페이지 수집 결함

* **[현상]:**
  네이버 카페 실시간 제목 검색 교차 검증(`is_article_already_in_cafe`) 수행 시, 존재하지 않는 404 URL(`https://m.cafe.naver.com/ca-fe/web/cafes/{club_id}/search/articles`)로 접속하여 네이버의 "페이지를 찾을 수 없습니다" 안내화면(404)이 뜸. 이로 인해 게시글 항목이 0개(`[]`)로 판정되어 이미 카페에 올린 기사를 감지하지 못하고 동일 기사가 중복 포스팅되는 문제 발생.

* **[원인]:**
  네이버 카페 모바일 SPA 웹사이트의 존재하지 않는 추정형 검색 라우팅 주소를 하드코딩으로 호출함.

* **[예방책]:**
  1. 웹 크롤러/자동화 봇 구현 시 명확히 검증되지 않은 추정형 SPA URL 사용을 엄격히 금지함.
  2. 네이버 카페 실시간 게시글 수집 시 100% 동작이 검증된 정식 메뉴 URL (`https://m.cafe.naver.com/ca-fe/web/cafes/{club_id}/menus/{board_id}`)을 사용함.
  3. 신규 크롤링/네비게이션 URL 작성 시 개발 단계에서 반드시 `page.screenshot()`으로 실측 화면을 캡처해 404 오류 화면 여부를 시각적으로 실측할 것.

---

## 2. 네이버 카페 스마트에디터 ONE 글쓰기 제출 후 성급한 리다이렉션 판정 및 추정 성공 결함

* **[현상]:**
  기사를 연속 작성할 때 1번째 기사 등록 클릭 후 네이버 서버가 저장을 마치기도 전에(4초 이내) 다음 기사 수집 페이지로 이동하여 네이버 서버 상에서 글 작성이 취소되나, 봇은 `elif "write" not in final_url:` 조건에 걸려 가짜 성공 알림 및 거짓 DB 기록을 처리함.

* **[원인]:**
  URL에 `write`가 없다는 약한 조건만으로 성공을 성급히 추정함.

* **[예방책]:**
  1. 약한 추정 성공 로직(`elif "write" not in final_url: success_published = True`)을 완전히 거부할 것.
  2. 등록 후 충분한 서버 저장 시간(6초 이상)을 보장하고, 실제 작성된 글 상세 페이지 주소(`articles/{id}`)로 이동했거나 게시판 목록 DOM에서 방금 쓴 제목을 직접 긁어 확인하는 **2중 실측 검증(Strict Verification)**에 성공했을 때만 `SUCCESS`를 반환할 것.
